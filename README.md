# Operasi Nadi Kerajaan

Game Sejarah Tingkatan 2, Bab 1 dan 2. Buka `index.html` dengan pelayar untuk bermain. Semua peta, ilustrasi, gaya, kod dan bunyi asas terkandung dalam fail ini; tiada pemasangan diperlukan.

## GitHub Pages

1. Ekstrak ZIP ini.
2. Gunakan repositori baharu supaya portal HistoryVerse sedia ada tidak berubah.
3. Muat naik `index.html` ke aras utama repositori (bukan fail ZIP). Fail lain dalam pakej adalah bahan rujukan dan sumber suntingan.
4. Buka Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. Tunggu penerbitan selesai dan buka pautan Pages yang diberikan GitHub.

Peta tidak memerlukan folder gambar tambahan. Fail index.html boleh dimuat naik sendirian. Buka pautan baharu untuk murid; pakej ini belum diterbitkan secara automatik.

## Urutan permainan

- Nama murid → intro CODE ERROR selama kira-kira 8 saat (boleh dilangkau).
- Atlas: 7 kerajaan, 5 label sungai, 8 pusat kerajaan. Kedah Tua mempunyai peta kecil untuk dua sungai dan dua pusat.
- Pemerintahan: pilih piagam, dekati wakil kerajaan dan hantar.
- Ekonomi: buka pintu air, tanam sawah, kemudian hantar lima hasil ke kegiatan ekonomi yang betul.
- Kecemasan: lindungi jeti, simpan makanan, buka laluan sungai dan hantar lebihan hasil.
- Transmisi terakhir: tafsir tiga mesej bekalan, baiki tiga alamat utusan dan cadangkan manfaat sungai untuk petempatan baharu.
- Laporan: pecahan markah, jawapan asal dan rekod tindakan; muat turun atau salin.

## Kawalan

Peta: seret label ke pin atau pilih label kemudian ketik pin. Leret peta, gunakan Zum dan tab Kedah Tua. Label dan nombor pin diacak bagi sesi baharu; lokasi geografi tidak diacak.

Simulasi: ketik objek/tanah atau tekan anak panah/WASD. Pilih alat/piagam/hasil dan gunakan tindakan apabila ejen dekat. Enter pada objek juga mengarahkan ejen menghampiri. Butang Tugasan seterusnya dan Petunjuk tindakan membantu jika tersekat. Selepas semua tugasan selesai, tekan Teruskan.

## Markah dan rekod

Peta 40 + pemerintahan 10 + ekonomi 20 + kecemasan 20 + latihan 10 = 100. Kesilapan pertama bagi setiap tugasan mengurangkan 1 markah; murid boleh membetulkan tindakan. Petunjuk tidak menolak markah. Tiada pemasa dalam misi selepas intro.

Latihan bertulis menggunakan padanan perkataan, termasuk KBAT. Ini alat maklum balas awal, bukan pemeriksa bahasa atau pengganti guru. Guru perlu menyemak jawapan asal dan mengesahkan jumlah akhir. Jawapan pertama disimpan bersama laporan.

Kemajuan disimpan pada pelayar/peranti semasa sahaja. Ia tidak dihantar kepada guru secara automatik. Gunakan Murid baharu untuk menggantikan sesi; salin laporan dahulu jika diperlukan. Mod peribadi atau tetapan pelayar mungkin menghadkan simpanan/muat turun. Bunyi bermula selepas interaksi dan boleh disenyapkan.

## Suntingan

Fail HTML siap guna mengandungi CSS dan JavaScript. Versi berasingan tersedia dalam `source/`. Jika menyunting sumber, jalankan `node source/build.cjs` dari mana-mana direktori untuk membina semula index.html (Node.js diperlukan untuk pembinaan sahaja, bukan bermain).

Baca SUMBER.md untuk rujukan dan batas peta; UJIAN.md untuk semakan versi ini.
